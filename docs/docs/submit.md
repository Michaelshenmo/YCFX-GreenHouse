# 提交文档

:::warning 这里是写给项目参与者看的临时界面

如果你没有参与，可以跳过此页

:::

项目接近完成后，你可以写一份小组的报告，发送给我，可以是Word格式，当然如果你会写标准Markdown最好

### 推荐的项目板块

- **概述** 简单讲一下你们的项目
- **使用资源** 使用到了那些器材，使用了哪些工具
- **时间线** 完成这个项目的时间线
- **最后实现功能** 实现了哪些功能
- **可以改进的地方** 简述项目仍然存在的问题、
- **源文件/参考资料** 比如设计图、源代码/参考的论文、文章

欢迎各位为本页提出意见
